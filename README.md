# .github

Página inicial da org: o GitHub mostra o [`profile/README.md`](profile/README.md) na home de [comite-popular-tech](https://github.com/comite-popular-tech) para qualquer visitante.

Só o `profile/` entra aqui. Templates de issue e de PR, `CONTRIBUTING.md` e outros arquivos de comunidade colocados neste repositório passam a valer para todo repositório da org que não tiver os próprios.

Ao criar ou remover uma iniciativa, atualizem a tabela do `profile/README.md`.
